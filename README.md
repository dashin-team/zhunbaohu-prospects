# 準保戶開發名單

行動優先的靜態網站，把「顧問式行銷－銷售流程／開拓準保戶」訓練中的名單分類、CAPMAN 評估與開發追蹤，做成可在手機上使用的工具。

線上使用：<https://dashin-team.github.io/zhunbaohu-prospects/>

## 資料存在哪裡？

所有名單都只存在**你正在使用的這支裝置、這個瀏覽器**的 localStorage，**不會上傳到伺服器**。

換手機、清除網站資料、使用無痕模式或換瀏覽器，名單就會消失。請定期用「備份」匯出 Excel 或 JSON，並把檔案存到你自己的雲端或電腦。

## 功能

- 新增／編輯／刪除準保戶
- 名單來源與連動細項（緣故市場、推薦介紹、陌生開發）
- 五大分類：職業、關係、人生階段、社群或巢、收入
- CAPMAN 六項評估，自動計算符合項數與開發優先序
- 開發狀態、銷售階段、聯絡日期、下次跟進日；逾期與今日待跟進會標示
- 搜尋、篩選、排序
- 統計儀表板（人數與圖表）
- 分類說明
- 匯出／匯入與工作簿相同欄位的 Excel（.xlsx），以及 CSV、JSON 備份
- 可選的「示範資料」為虛構練習筆數，可一鍵清除

## 本機預覽

以任何靜態伺服器開啟此資料夾即可，例如：

```bash
python3 -m http.server 8080
```

然後用瀏覽器開啟 <http://127.0.0.1:8080/>。

Excel 欄位與 `準保戶市場開發名單.xlsx` 工作簿一致，可來回匯入匯出。
